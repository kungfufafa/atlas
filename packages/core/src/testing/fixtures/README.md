# Independent daily-file regression fixtures

All content is synthetic. Generators and independent oracles live under
`scripts/daily-files-corpus/`; the predeclared case list and attempt ledger are
under `docs/architecture/daily-files-corpus.md`.

- `spreadsheet-openpyxl-comments.xlsx`: X01, openpyxl 3.1.5. Plain comment with
  author, absolute relationships, hidden sheet, zero-prefixed ID, date,
  validation, hyperlink and freeze panes.
- `spreadsheet-openpyxl-table.xlsx`: X04, openpyxl 3.1.5. Named table, totals,
  structured formula, and two-color conditional formatting.
- `pdf-scanned-reportlab.pdf`: F03, Pillow plus reportlab; actual image-only page.
- `pdf-navigation-pypdf.pdf`: F04, reportlab plus pypdf; bookmarks, attachment
  and internal destination. Merge/split currently refuse it to prevent loss.
- `pdf-libreoffice-report.pdf`: W01, python-docx source edited by Atlas then
  converted with explicitly injected test LibreOffice. pypdf verifies actual
  text; this fixture reproduced anydoc's false image-only classification.
- `spreadsheet-chart.xlsx`: earlier independent openpyxl chart workbook.
  Cell reads and writes use a dedicated OOXML preservation path; layout changes
  and chart recalculation remain guarded.
- `spreadsheet-chart-source-openpyxl.xlsx`: X03, openpyxl 3.1.5. Editing B2
  preserves chart series, drawing relationships, styles and other cells.
- `word-tracked-python.docx`: original D03, python-docx 1.2.0 and OOXML insertion
  wrapping a whole paragraph. Retained for historical corpus consistency;
  LibreOffice omits this source's body paragraph, so it is structural evidence.
- `word-tracked-runs-python.docx`: independent inline-run tracked insertion,
  generated by `generate-tracked-inline.py`. Supports rejection/acceptance
  assertions and meaningful before/after rendering.
- `pptx-merged-python.pptx`: P03, python-pptx 1.0.2; merged anchor plus
  continuation cell. Text edits preserve merge geometry and all unrelated parts.

The two new XLSX fixtures reproduce ExcelJS assumptions about part names and
absolute OPC relationships. The tests do not use ExcelJS to generate the input
that ExcelJS is then asked to read.

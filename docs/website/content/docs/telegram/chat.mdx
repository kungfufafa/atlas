Once the bridge is running and your account is authorized, here is how the bot behaves and what you can send it.

## Private chat behavior

Private chat is the simplest mode.

Once paired or allowlisted:

- normal messages go to the Atlas agent
- the bot keeps a Telegram chat session
- Telegram commands work immediately

If an unlinked user opens the bot, Atlas asks for the chat access code instead of sending the message to the agent.

## Group chat behavior

Atlas supports Telegram groups, but it is intentionally conservative about when it replies.

By default, in a group, the bot responds when the message is:

- a slash command like `/status`
- a reply to one of the bot's messages
- a direct mention like `@your_bot_name hello`

If Atlas receives an otherwise authorized file without the required mention or reply, it explains why the file was ignored. Resend it with a mention in the caption, or ask an administrator to disable **Channel controls → Groups → Require mention or reply**. Telegram must deliver the message to the bot; check bot privacy settings if group files never arrive.

### Group topics and profiles

In Telegram supergroup topics, each topic can use its own Atlas profile.

- `/profile` inside a topic changes only that topic
- new topics use the default Telegram profile until you switch them
- `/profile` in the main group chat changes the group-level profile
- `/org` stays group-level, so switch org first if a topic needs a profile from another org

## Telegram commands

These commands are available in Telegram:

| Command | What it does |
| --- | --- |
| `/start` | Welcome and help |
| `/help` | Show command help |
| `/stop` | Stop the current in-progress reply |
| `/clear` | Clear chat history |
| `/compact` | Compact conversation history |
| `/new` | Start a new conversation |
| `/org` | Choose or switch organization |
| `/profile` | Choose or switch profile |
| `/status` | Show server and model status |
| `/attach` | Send the latest file saved in this conversation |

## Supported message types

Telegram can send more than plain text into Atlas.

Supported inputs include:

- text messages
- photos
- voice notes and audio messages
- supported documents such as `pdf`, `docx`, `xls`, `xlsx`, `csv`, `txt`, and `md`

Use Telegram's **File** attachment option for the original document, or send a photo. Add the requested job in its caption, such as “Summarize this PDF and send a Word report.” Pasted preview text does not provide the original file.

Supported work files include `.xlsx`, `.xls`, `.xlsm`, `.xlsb`, `.csv`, `.pdf`, `.docx`, `.txt`, `.md`, and `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif` images. Atlas saves originals to the replying profile's **Artifacts**, uses the matching reader, and saves finished deliverables there. Photos also reach the model as real image bytes. Voice notes and audio originals are saved before their existing transcription flow.

The hosted Telegram bridge accepts documents and audio up to **20 MB**, and images up to **5 MB**. Atlas itself caps audio at **25 MB**. All authorized senders can submit file jobs without a separate account pairing; blocked senders and read-only viewers cannot. Workspace tool restrictions still apply. Unsupported types and failed downloads or saves receive a rejection instead of a guess.

Legacy Excel workbooks are read or converted to a new `.xlsx` for editing; macros are not executed or carried into the result. Self-hosted XLS/XLSB conversion requires LibreOffice, which is included in the Atlas container.

Continue edits in the same chat or topic so Atlas can use the current file job. Finished spreadsheets, Word documents, slide decks, summaries, and images return through the existing artifact delivery flow.

## Rich Markdown replies

Agents can reply in normal Markdown-style text. Atlas converts a safe subset into Telegram rich formatting.

Supported formatting includes:

- `**bold**`
- `*italic*`
- `__underline__`
- inline code
- fenced code blocks
- headings
- simple links

If Telegram rejects the rich rendering, Atlas falls back to plain text.

## Saved artifacts and share links

When the agent saves a file (spreadsheet, document, deck, or other artifact), Atlas sends that file in the Telegram chat when it is within 25 MB, then posts a **Publish-style share link**.

- The link uses the same unguessable `/s/{token}` URLs as dashboard Publish — no Atlas login required to open it.
- Anyone who can read the Telegram message can open the link until the share is revoked from the web app.
- Set **Web Public URL** in Atlas settings (or `ATLAS_WEB_PUBLIC_URL`) so channel footers include absolute links.

To get the latest saved file again later, send `/attach` or ask in plain language — for example, “send the file” or “attach it”. `/attach` sends the file without starting a new agent turn. If the file is too large for Telegram, use the share link instead.

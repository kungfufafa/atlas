# Referensi artefak child melalui parent — 2026-09-08

Subagent dalam mode publikasi host kini mengembalikan referensi artefak kepada parent setelah pekerjaannya selesai. Host membaca publikasi yang sudah tersimpan, mengambil maksimal 20 referensi, dan menandai bila masih ada kandidat lain. Referensi hanya memuat ID sesi child, ID publikasi, waktu, nama berkas, MIME, ukuran dan SHA-256. Metadata privat snapshot maupun teks yang dikarang child tidak digunakan untuk membuat referensi.

Jika pencarian metadata gagal, teks dan status hasil child tetap dipertahankan dengan status referensi `unavailable`. Tidak ada pengulangan efek child. Pembatalan tetap mengikuti jalur cancellation. Referensi pada checkpoint lama diperlakukan sebagai data historis dan tidak dipulihkan sebagai bukti akses saat ini.

Parent dapat menemukan publikasi child tersimpan melalui `GET /v1/sessions/:sessionId/delegated-artifact-publications` dan metode SDK `listDelegatedArtifactPublications`. Endpoint membaca hubungan parent–child yang sudah tersimpan, memeriksa identitas parent dan izin child dengan aktor asli, lalu memeriksanya kembali setelah await. Pembacaan byte dan pencabutan tetap memakai endpoint sesi child dengan otorisasi terbaru. Discovery metadata tidak membuka snapshot store.

Pagination mengurutkan kandidat berdasarkan waktu dan ID secara menurun. Host mengambil paling banyak 101 kandidat mentah, memeriksa maksimal 100, dan berhenti ketika batas hasil yang diminta tercapai. Cursor menunjuk kandidat terakhir yang diperiksa; baris sah yang belum dikembalikan tidak dilompati. Halaman kosong dapat mempunyai continuation karena kandidat lain masih ada. Child yang stale atau ditolak dengan 404 tidak ditampilkan; kegagalan infrastruktur yang tak terduga membuat seluruh permintaan tidak tersedia.

Cursor memakai AES-256-GCM dengan kunci acak lokal host, terikat pada organisasi, profil, identitas dan generasi parent, aktor/channel worker serta filter. Cursor kedaluwarsa setelah sepuluh menit dan tidak berlaku setelah host restart. Konsumen memulai listing baru dalam keadaan itu. Cursor tidak memberi izin akses, dan tidak menampilkan ID kandidat yang ditolak.

Enam kasus proses dari increment sebelumnya diperluas; tidak dihitung lagi sebagai enam tes baru. [Inventaris](../../../../outputs/hermes-evidence/2026-09-08/publication-delegated-discovery/test-inventory.json) memakai file, judul dan kemunculan kasus, tanpa menjumlahkan rerun. [Tipe produksi, tipe delapan berkas tes, serta lint 24 berkas](../../../../outputs/hermes-evidence/2026-09-08/publication-delegated-discovery/final-static-gates.json) lulus.

Fixture integrasi memakai AgentService, tool loop, persistence dan Bash yang sebenarnya, dengan respons API/callback native sintetis. Kasus meliputi sibling terpisah, metadata palsu dalam teks child, 23 publikasi dengan pengiriman awal dibatasi 20, kegagalan metadata tanpa replay, pencabutan, perubahan identitas child saat pembacaan metadata, dan pembatalan. Uji discovery melewati lebih dari 100 kandidat yang tidak dapat diakses, lalu tetap menemukan semua referensi sah berikutnya. Jalur Hono/SDK membaca byte dan mencabut publikasi melalui child setelah discovery parent.

Enam [konsumen Bun baru](../../../../outputs/hermes-evidence/2026-09-08/publication-delegated-discovery/root-final-process-readback.json) membuka SQLite dan service baru setelah koneksi DB pembuat ditutup. Dua kasus positif, pemilik dan worker Discord, menemukan referensi melalui parent, membaca byte dengan hash/ukuran yang cocok, mencabutnya, lalu mendapatkan daftar kosong. Empat kasus penghapusan/perubahan channel parent tidak mengembalikan referensi child dan tidak memperoleh store. Root memeriksa enam PID yang berbeda dari pembuat serta 13 binding source sebelum, selama dan setelah tiap proses. Ini menguji service pada subprocess; HTTP diuji terpisah melalui Hono.

Seluruh kegagalan awal dipertahankan. [Gate fixture pertama](../../../../outputs/hermes-evidence/2026-09-08/publication-delegated-discovery/logs/agent-behavior-v1.log) mempunyai 7 pass/12 fail karena nama berkas sintetis tidak cocok dengan basename sourcePath, sehingga ditolak sebelum discovery. Tipe metode baru awalnya kurang anotasi parameter, konfigurasi tipe tes eksternal belum menemukan tipe Bun, dan operasi XOR pada tes melanggar lint. Koreksinya lulus gate final; kegagalan tersebut bukan hasil tugas model. Detail ada pada [verifikasi](../../../../outputs/hermes-evidence/2026-09-08/publication-delegated-discovery/verification.json).

Root dan agent saling meninjau source. Review menambahkan otorisasi child setelah pengambilan metadata untuk menutup perubahan selama await yang diuji. Ini bukan review dengan kepenulisan independen seluruh sistem atau rerun penuh oleh pihak terpisah. Pagination dan referensi awal menggambarkan keadaan yang diperiksa, bukan snapshot transaksi lintas baris atau lease izin atomik. Batas kandidat tidak menjamin biaya query pada skala tak terbatas; adapter memori masih menyaring dan mengurutkan store. Pengujian restart menggunakan producer teks dan metadata sintetis, bukan pemulihan server lengkap, producer native, atau pembuktian quiescence proses.

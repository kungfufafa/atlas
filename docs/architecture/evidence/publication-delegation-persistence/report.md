# Delegasi tersimpan dan akses setelah restart — 2026-09-08

Child publikasi kini dibuat bersama catatan hubungan yang mengikatnya ke sesi parent, organisasi, profil, pemilik, turn parent, handle subagent dan record eksekusi aslinya. SQLite memeriksa baris terkait lalu menyimpan child dan hubungan dalam satu transaksi immediate. Adapter memori menjalankan seluruh pemeriksaan sebelum dua penulisan sinkron. Konflik handle/run membatalkan pembuatan child; tidak meninggalkan sesi baru tanpa hubungan.

SubagentService menangkap referensi run serta metadata parent sebelum await berikutnya dan mempertahankannya pada checkpoint awal, penyelesaian maupun pembatalan. ID turn parent yang berasal dari ALS harus sama dengan checkpoint dan handle. ID turn percakapan tidak dianggap sebagai foreign key execution run. Principal child yang aktif memerlukan parent aktif dan run child yang masih running.

Akses hasil tersimpan memakai hubungan tersebut untuk memeriksa kembali identitas parent, child dan run, kemudian memakai ACL parent dengan aktor asli. Worker mempertahankan bukti channel parent. Read dan revoke mengikuti izin saat ini; publikasi baru melalui jalur konsumen generik ditolak. Penanda internal berupa boolean mencegah child dianggap sebagai sesi biasa ketika tenant dan channel diubah bersama, sementara pembacaan payload hubungan tetap dibatasi organisasi.

Hubungan tidak dihapus ketika parent atau run hilang, sehingga keadaan itu tetap terdeteksi dan akses ditolak. Penghapusan child menghapus hubungannya melalui mekanisme cascade yang ada. Ini bukan tombstone permanen untuk setiap ID yang pernah digunakan.

SubagentService tidak lagi memperlakukan checkpoint nonterminal sebagai proses yang hidup kembali setelah lease kedaluwarsa. Record tersebut dinyatakan tidak tersedia tanpa replay atau penulisan. Snapshot terminal harus mempunyai identitas dan status row/handle yang konsisten; hasil non-null juga harus cocok dengan status terminal. Poll/wait atas snapshot terminal yang dipulihkan bersifat read-only. Hasil null dari format lama tetap tidak diketahui, tanpa mengarang keberhasilan.

Turn parent yang salah ditolak sebelum sesi child atau efek Bash dibuat. Hasil tool dan snapshot tetap dipertahankan tanpa replay. Respons provider API dan callback native pada fixture tetap sintetis; ini bukan panggilan subscription atau penilaian kualitas model.

Pengujian SQLite dengan koneksi, AgentService dan store baru mencakup pasangan status running/running, completed/succeeded, failed/failed dan cancelled/cancelled, untuk pemilik maupun worker Discord. Kasus negatif mencakup penghapusan parent/run, perubahan pemilik, profil, channel dan waktu pembuatan, pencabutan keanggotaan, serta penghapusan parent setelah byte snapshot dibaca tetapi sebelum dikembalikan.

Dua kasus positif membaca hash/ukuran byte yang tepat, mendaftarkan publikasi, mencabutnya dan memastikan byte tidak lagi tersedia. Empat kasus perubahan channel atau penghapusan parent ditolak sebelum store diperoleh, untuk pemilik dan worker Discord. Ini bukan penolakan automatic approval review. [Verifikasi lengkap](../../../../outputs/hermes-evidence/2026-09-08/publication-delegation-persistence/verification.json) memisahkan kegagalan produk, fixture dan konteks pengujian.

Root dan agent saling meninjau source. Review menemukan beberapa counterexample di atas dan koreksinya diperiksa kembali. Root membaca fixture proses, mencocokkan receipt final dan membaca ulang seluruh payload arsip; ini bukan rerun independen seluruh sistem atau review arsip oleh pihak terpisah.

Konsumen proses terpisah memakai producer teks dan metadata sintetis. Pengujian membuktikan pembacaan artefak tersimpan dalam proses baru; belum membuktikan restart server lengkap, pemulihan proses producer/native, kepemilikan proses lintas host, atau quiescence descendant. Hubungan mengikat ID dan waktu pembuatan baris, bukan lease izin atomik atau perlindungan terhadap seluruh manipulasi database/host. Pemeriksaan ulang mengurangi celah await yang diuji; perubahan ABA yang tidak teramati tidak dikecualikan. Persiapan batal masih dapat meninggalkan metadata child, dan budget wait yang sudah ada tidak menjamin semua inner work selesai.

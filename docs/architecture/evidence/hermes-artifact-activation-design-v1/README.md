# Persisted-chat activation design

A source-bound plan identifies ordinary persisted-chat wiring and the missing admission prerequisites across cached sessions, worker invokers, persisted wrappers, executable loading, local MCP, dynamic process roots and shared private-store protection.

This is a prospective, source-only design: zero tests, provider calls or implementation edits. The copied plan remains historical. The later [principal review](../hermes-publication-turn-principal-v1/independent-review/review.md) supplies the final guard-order and base-context qualifications.

Mandatory pre-load/pre-spawn admission must bind actual roots and preserve trusted evidence after temporary-root cleanup; the base session context alone cannot provide that evidence.

Unsafe same-UID processes, other profiles, stale MCP connections and trusted fixed workers require explicit deployment-wide scope; publication-profile checks alone do not protect old private blobs.

No code, tests, production activation, complete artifact UX, automatic Bash/Python publication or model comparison was delivered by this design.

The pack preserves selected top-level evidence; full source trees, runtime states and omitted dependency directories remain at the original private paths. Original documents retain their bytes and historical readiness wording. Neither packaging nor local gates prove a live Atlas/Hermes improvement.

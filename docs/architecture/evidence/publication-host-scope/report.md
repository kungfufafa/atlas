# Scope eksekusi host untuk publikasi — eksplorasi terpisah, 2026-09-08

Core sekarang menyediakan batas eksekusi wajib yang dapat dipasang host pada API maupun runtime native. Penolakan sebelum continuation mencegah tool berjalan. Core menyimpan hasil protected execution sendiri: wrapper menerima `Promise<void>`, hanya boleh memulai satu kali, tidak dapat mengganti hasil melalui return, dan pekerjaan yang tidak di-await tetap ditunggu. Kegagalan wrapper setelah execution dimulai tidak menghapus receipt atau memicu replay. Lifecycle publikasi yang bersifat diagnostik tetap berada di dalam scope tersebut.

Server menghubungkan scope dengan principal per turn, workspace profil canonical, dan kebijakan runtime dari [increment sebelumnya](../publication-runtime-policy/report.md). `AsyncLocalStorage.run` menyimpan identitas invocation di host, tanpa menambahkan capability ke `ToolContext`. Runner Bash/Python yang tersimpan di cache mengambil scope aktif setiap kali dipanggil. Konteks yang diklon, panggilan paralel dengan ID provider yang sama, scope yang sudah ditutup, pembatalan, dan pemanggilan yang mencoba meminjam identitas tool lain ditangani secara terpisah. Lifecycle dapat memakai execution ID yang sama untuk snapshot byte.

Total pada increment ini adalah **129 tes unik / 709 assertion, termasuk 30 tes baru**. Angka regresi tidak ditambahkan sebagai bukti independen di atas tes yang sama pada increment terdahulu. Tes provider core menggunakan respons fixture, bukan panggilan provider langsung. Server menjalankan Bash nyata pada macOS melalui satu runner cache yang dipakai dua invocation paralel. Gate regresi juga menjalankan fixture Bash/Python lama dengan sandbox Atlas tetap aktif, dalam konteks host yang diperlukan untuk `sandbox-exec`.

Review sumber menemukan dua celah sebelum penutupan: signal perlu diperiksa sebelum bootstrap Python, dan workspace perlu dibandingkan sebelum tool tanpa proses seperti `write_file` masuk. Keduanya diperbaiki, dengan tes untuk workspace salah/hilang, cancellation kedua runner, dan cancellation saat validasi awal tertahan. Signal asli tetap dipakai meskipun konteks klon memasok signal baru. Tes missing-scope membuktikan penolakan dan tidak adanya file hasil; posisi pemeriksaan sebelum bootstrap diverifikasi dari sumber, tanpa klaim trace proses bootstrap tersendiri. Reviewer kemudian membaca ulang koreksi dan tidak menemukan blocker dalam cakupan tersebut; ia tidak menjalankan ulang suite server.

Kontrak callback core awal masih mengekspos objek hasil yang bisa diubah wrapper; versi itu dipertahankan dan diganti sebelum gate akhir. Kegagalan formatter fixture core, tiga implicit-any produksi, konfigurasi tipe Bun eksternal, serta dua kesalahan typing fixture server juga disimpan bersama koreksi dan log lulus. Tidak ada kegagalan tes perilaku pada dua gate server yang dijalankan dalam increment ini; gate pertama berisi enam tes, gate akhir mencakup sepuluh tes scope di dalam 54 tes regresi.

**Ini belum aktivasi publikasi otomatis pada AgentService.** Pengujian cache di atas menggunakan runner yang sebenarnya, tetapi belum membuktikan alur HTTP terautentikasi melalui cache sesi AgentService. Lifecycle masih memerlukan inventaris lengkap workspace/runtime/temp yang diterima; integrasi snapshot pada tes ini hanya memakai producer `write_file` sederhana. Admission runtime tidak dengan sendirinya menjamin staging, kepemilikan byte keluaran Bash/Python, atau publikasi. Discovery dan lifetime MCP/custom/skill/dedicated worker, konsumen UI/kanal, serta pemulihan alur penuh masih terbuka.

Tidak ada jaminan seluruh authority OS, hardlink alias, perubahan host atomik sesudah pemeriksaan, pembatalan setelah spawn, rollback efek, atau pencabutan receipt yang sudah diserahkan. Patch ini juga tidak membuktikan kualitas provider/subscription nyata. C10 asal dan salinan pengembangan sebelumnya tetap utuh; isi tugas/kalibrasi baru, renderer yang dihentikan, dan admission studi tidak disentuh. Hasil pembanding sah terakhir tetap [Atlas 44/54 dan Hermes 46/54](../hermes-native-files-v3-c9-confirmation/report.md), sehingga klaim setara atau lebih baik belum terpenuhi.

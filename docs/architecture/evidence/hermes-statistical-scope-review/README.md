# Statistical scope evidence

This directory preserves the source-only review and a prospective design note. It contains no evaluation outcomes or heldout task contents and changes no study protocol, threshold or score. Earlier DeepSeek evidence was inherited in context; neither review claims global blinding.

- `review.md` and `sources.json` are byte-identical copies of the completed native MiMo statistical scope review. The source inventory binds the preregistrations and analyzer read at that checkpoint.
- `prospective-options.md` gives future finite-population sampling options, a loss-only NI argument, heterogeneous fixed-quota concentration proof, sample-cost examples, quality-confidence considerations and a separately defined certified-completion endpoint. It is not a launched or fully powered study.
- `calculate-options.py` and `numeric-calculations.json` contain deterministic arithmetic only. The script uses the Python standard library, reads no evaluation data and calls no provider.
- `prospective-sources.json` records primary-source URLs, access limitations, local source hashes and the requested design scope. `manifest.json` binds the preserved files.

Current frozen controls and all prior results remain authoritative for their own studies. These notes neither replace the current bootstrap analysis nor authorize post-hoc rescoring or another live run.
